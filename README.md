# 🎂 Dhruvi's First Birthday — A Year of Memories ❤️

> **A tiny celebration of one big milestone — Dhruvi's 1st Birthday 🎉**

Welcome to **Dhruvi's First Birthday**, a special interactive birthday memory website created to celebrate the **first beautiful year of Kartik Negi (Dhruvi)**.

This project is more than just a birthday website — it's a digital collection of **memories, photographs, videos, music, animations, and heartfelt wishes** created especially for his first birthday.

---

## 🌟 About The Project

**Dhruvi's First Birthday** is a personalized birthday experience designed to preserve and showcase the memorable moments from Dhruvi's first year.

The website brings together:

- 📸 Special photographs
- 🎥 Memorable videos
- 🎵 Background music
- 🎈 Birthday animations
- 💖 Heartfelt birthday wishes
- ✨ Interactive sections
- 🎂 First birthday celebration
- 📱 Responsive design for mobile and desktop

The goal was to create something that feels less like a normal website and more like a **digital memory album**.

## ❤️ Why I Created This

A child's first year is filled with countless little moments that become precious memories.

Instead of creating a traditional birthday card, I wanted to build something that could **preserve those memories digitally** and allow family and friends to experience them through an interactive website.

This project combines my interest in **web development** with something personal and meaningful.

> **"Some memories are too special to stay only in our phones — so I turned them into a little piece of the web." ❤️**

---

## 🎯 Project Goals

- Create a personalized digital birthday experience
- Preserve memories from Dhruvi's first year
